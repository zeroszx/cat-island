      Pengaturan

      Belum punya key? Cara membuatnya (gratis, ±3 menit)
      1. Buka Google Cloud Console, masuk dengan akun Google, lalu buat project baru (nama bebas, mis. "Noctark").
      2. Aktifkan YouTube Data API v3 untuk project itu: klik Enable.
      3. Buka Credentials → Create credentials → API key, lalu salin key yang muncul.
      4. Disarankan: klik key tadi → API restrictions → Restrict key → pilih YouTube Data API v3 → Save.
      5. Tempel key di kolom di atas, lalu klik Simpan. Noctark akan langsung mengujinya.

      Tanpa kartu kredit. Kuota gratis ±100 pencarian judul per hari; hasil disimpan di cache, jadi lagu yang sama tidak dihitung ulang. Jangan bagikan key-mu ke orang lain.

      Gaya equalizer Bergerak mengikuti suara yang sedang diputar
      Equalizer suara Atur bass, vokal, dan treble. Langsung terdengar & tersimpan. Klik ganda slider = 0.

      Memeriksa Equalizer APO…

      1. Unduh & instal Equalizer APO (gratis).
      2. Di akhir instalasi muncul Configurator: centang speaker/headphone yang kamu pakai → OK → restart Windows.
      3. Kembali ke sini, klik Hubungkan. Windows meminta izin admin satu kali.
